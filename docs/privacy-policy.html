Politique de confidentialité

Extension Chrome « Saint-Maur Périscolaire Exporter »

Dernière mise à jour : septembre 2025

Cette extension Chrome (« Saint-Maur Périscolaire Exporter ») permet aux familles de Saint-Maur-des-Fossés d'exporter leurs réservations périscolaires du Portail Famille (AgoraPlus) au format ICS, et de convertir les factures PDF en CSV.

Nous prenons très au sérieux la protection de vos données personnelles. Cette politique décrit quelles données sont collectées, comment elles sont utilisées, et quels sont vos droits.

1. Responsable du traitement

L'extension est développée et maintenue par un contributeur indépendant. Aucune entreprise ou organisation n'est impliquée dans la collecte de données. Pour toute question, vous pouvez ouvrir une issue sur le dépôt GitHub : github.com/zhitongLIU/saint_maur_family_portal_extension.

2. Données collectées et traitement

2.1 Données de session du Portail Famille

  • L'extension lit l'identifiant de session (SESSION_ID_smdf) stocké par le Portail Famille dans le sessionStorage du navigateur, uniquement lorsque vous cliquez sur l'icône de l'extension.
  • Cet identifiant est utilisé pour interroger l'API du Portail Famille (smdf.agoraplus.fr / portalssl.agoraplus.fr) afin de récupérer la liste de vos enfants et leurs réservations.
  • Aucune donnée de session n'est transmise à un serveur tiers (autre que le Portail Famille lui-même, que vous utilisez déjà).

2.2 Réservations et calendrier

  • Les données de réservation (dates, horaires, activités, annulations) sont récupérées depuis l'API du Portail Famille et utilisées exclusivement pour générer un fichier ICS ou pour synchroniser les événements vers votre compte Google Calendar (avec votre autorisation explicite).
  • Ces données ne sont jamais envoyées à un serveur tiers (autre que le Portail Famille ou Google Calendar si vous activez la synchronisation).

2.3 Factures PDF

  • Les fichiers PDF que vous glissez-déposez dans l'extension sont traités localement dans votre navigateur, à l'aide de la bibliothèque PDF.js.
  • Aucune donnée extraite des PDF (montants, descriptions, catégories) n'est transmise à un serveur externe.

2.4 Synchronisation Google Calendar (OAuth 2.0)

  • Si vous choisissez d'utiliser la fonction « Sync to Google Calendar », l'extension demande votre autorisation via le protocole OAuth 2.0.0
  • Les événements sont créés directement dans votre calendrier Google via l'API Google Calendar. L'extension ne stocke ni ne transmet vos identifiants Google à aucun autre service.
  • Vous pouvez révoquer l'accès à tout moment depuis votre compte Google.

2.5 Stockage local (chrome.storage.local)

  • L'extension stocke localement, dans le navigateur, les paramètres suivants :
    • Identifiant de session (temporaire, pour la durée de la session active)
    • Période d'export sélectionnée (dates début/fin)
    • Jour de rappel mensuel de paiement (optionnel)
    • Jeton d'accès OAuth Google (temporaire, pour la synchronisation)
  • Ces données ne quittent jamais votre navigateur et ne sont pas accessibles par le développeur.
  • Les données de session expirent avec votre session Portail Famille.

3. Base légale du traitement

Le traitement de vos données repose sur votre consentement explicite : vous utilisez activement l'extension et choisissez les fonctionnalités que vous activez (export ICS, synchronisation Google Calendar, conversion PDF).

4. Durée de conservation

  • Les données de session et jetons OAuth sont conservés temporairement pendant la session active et supprimés automatiquement à la déconnexion ou à l'expiration du jeton.
  • Les paramètres utilisateur (période d'export, rappel) sont conservés localement jusqu'à ce que vous les modifiiez ou que vous désinstalliez l'extension.
  • Les fichiers ICS générés et les PDF importés ne sont pas conservés par l'extension — ils sont sous votre contrôle sur votre système de fichiers.

5. Destinataires des données

  • Portail Famille (AgoraPlus) : destinataire nécessaire pour récupérer vos réservations (vous êtes déjà utilisateur de ce service).
  • Google Calendar : destinataire uniquement si vous activez la synchronisation Google Calendar.
  • Aucun autre destinataire. Le développeur de l'extension n'a pas accès à vos données personnelles.

6. Transferts hors UE

Les données échangées avec Google Calendar peuvent être traitées sur des serveurs situés aux États-Unis. Ce transfert est encadré par les clauses contractuelles types (CCT) de Google. Le Portail Famille (AgoraPlus) est hébergé en France.

7. Vos droits

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès à vos données
  • Droit de rectification
  • Droit à l'effacement (suppression des données stockées localement)
  • Droit à la limitation du traitement
  • Droit d'opposition
  • Droit à la portabilité

Pour exercer ces droits, vous pouvez simplement désinstaller l'extension — toutes les données stockées localement seront supprimées. Pour les données hébergées par le Portail Famille ou Google, veuillez contacter directement ces services.

Pour toute question, ouvrez une issue sur GitHub.

8. Sécurité

L'extension utilise chrome.storage.local (isolé par le navigateur) et le protocole HTTPS pour toutes les communications réseau. Aucune donnée n'est transmise en clair. Le code source est ouvert et auditable sur GitHub.

9. Modifications de cette politique

Cette politique peut être mise à jour. La date de « Dernière mise à jour » en haut de page indique la version en vigueur.
